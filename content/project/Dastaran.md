:::project-section{type="text"}
Company portfolio website of Dastaran. It showcases our projects and gives an insight into our background, passion for web development and design, and the technologies we work with.

Built with Astro, TypeScript, and Tailwind CSS. The homepage covers a short intro, projects, skills, experience, and contact. The blog loads Markdown posts from a backend API at build time. The site is set up for SEO and social sharing, with accessible UI on Base UI and shadcn/ui.
